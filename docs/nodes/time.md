# 時間 (Time)

時間・タイマー・日時の取得・計算を行うノード群です。

---

| 英語名           | 日本語名               | 説明                             |
| ---------------- | ---------------------- | -------------------------------- |
| Get Delta Time   | Delta Timeを取得       | 前フレームからの経過時間を取得   |
| Stopwatch        | ストップウォッチ       | ストップウォッチを扱う           |
| Interval Timer   | 周期タイマー           | 一定周期でトリガーする           |
| Reset Time Scale | 時間スケールをリセット | Time Scale を初期値へ戻す        |
| Get Time Scale   | 時間スケールを取得     | 現在の Time Scale を取得         |
| Set Time Scale   | 時間スケールを設定     | Time Scale を設定する            |
| Get Current Time | 現在時刻を取得         | 現在時刻を取得する               |
| Get Uptime       | 起動経過時間を取得     | アプリ起動後の経過時間を取得する |
