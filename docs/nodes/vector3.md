# Vector3

3D ベクトル（X/Y/Z）の生成・演算・変換を行うノード群です。

---

| 英語名            | 日本語名         | 説明                  |
| ----------------- | ---------------- | --------------------- |
| Get BP Vector3    | BP Vector3を取得 | BP Vector3 を取得する |
| Set BP Vector3    | BP Vector3を設定 | BP Vector3 を設定する |
| Vector3           | Vector3          | Vector3 リテラル      |
| Scale Vector3     | Vector3 スケール | スカラー倍            |
| Dot Vector3       | Vector3 内積     | 内積を返す            |
| Add Vector3       | Vector3 加算     | 加算                  |
| Cross Vector3     | Vector3 外積     | 外積を返す            |
| Normalize Vector3 | Vector3 正規化   | 正規化ベクトルを返す  |
| Subtract Vector3  | Vector3 減算     | 減算                  |
| Lerp Vector3      | Vector3 補間     | 線形補間              |
| Distance Vector3  | Vector3 距離     | 2点間距離を返す       |
| Length Vector3    | Vector3 長さ     | ベクトル長を返す      |
| Make Vector3      | Vector3を作成    | Vector3 を作成する    |
| Break Vector3     | Vector3を分解    | Vector3 を分解する    |
