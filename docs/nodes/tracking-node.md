# トラッキング (Tracking)

モーションキャプチャ・フェイストラッキングのデータをノードで取得・利用するノード群です。

---

| 英語名              | 日本語名               | 説明                         |
| ------------------- | ---------------------- | ---------------------------- |
| Get Tracking State  | トラッキング状態を取得 | トラッキング状態を取得する   |
| Get Hand Position   | 手の位置を取得         | 手の位置情報を取得する       |
| Get Head Position   | 頭の位置を取得         | 頭の位置情報を取得する       |
| Get Face BlendShape | 顔BlendShapeを取得     | 顔の BlendShape 値を取得する |
