# パーティクル (Particle)

パーティクルシステムの再生・停止・パラメータ制御を行うノード群です。

---

| 英語名             | 日本語名               | 説明                       |
| ------------------ | ---------------------- | -------------------------- |
| Pause Particle     | パーティクルを一時停止 | パーティクルを一時停止する |
| Stop Particle      | パーティクルを停止     | パーティクルを停止する     |
| Play Particle      | パーティクルを再生     | パーティクルを再生する     |
| Restart Particle   | パーティクルを再起動   | パーティクルを再起動する   |
| Emit Particle      | パーティクルを発生     | パーティクルを発生させる   |
| Set Particle Speed | パーティクル速度を設定 | パーティクル速度を設定する |
