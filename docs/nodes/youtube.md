# YouTube

YouTube Live のチャット・スーパーチャット・メンバーシップイベントを受信するノード群です。

---

| 英語名                     | 日本語名                  | 説明                               |
| -------------------------- | ------------------------- | ---------------------------------- |
| On YouTube SuperChatAmount | YouTube Super Chat 金額時 | Super Chat の金額イベントで実行    |
| On YouTube CommentMatch    | YouTube コメント一致時    | 条件に一致するコメント受信時に実行 |
| On YouTube Event           | YouTubeイベント受信時     | YouTube イベント受信時に実行       |
