# OSC

OSCメッセージの送受信を行うノード群です。専用 Controller（GoodLiveClimaxController）とのデータ連携のほか、外部ソフトウェアとの OSC 通信にも対応します。

---

| 英語名       | 日本語名          | 説明                     |
| ------------ | ----------------- | ------------------------ |
| On OSC Event | OSCイベント受信時 | OSC イベント受信時に実行 |
| Send OSC     | OSC送信           | OSC メッセージを送信する |
