# Asset（アセット）

シーン内のアセット（3D オブジェクト・VRM アバター等）の表示・非表示・参照取得を行うノード群です。

---

| 英語名                   | 日本語名               | 説明                             |
| ------------------------ | ---------------------- | -------------------------------- |
| Asset Settings           | Asset Settings         | アセット設定ノード               |
| Asset                    | アセット               | アセット参照/指定ノード          |
| Execute Asset            | アセットを実行         | アセットの処理を実行する         |
| Get Asset Is Enabled     | アセット有効状態を取得 | アセットの有効状態を bool で取得 |
| Get Screen Average Color | スクリーン平均色を取得 | スクリーンの平均色を取得         |
| Toggle Enabled           | 有効状態を切り替え     | アセットの有効状態を切り替える   |
