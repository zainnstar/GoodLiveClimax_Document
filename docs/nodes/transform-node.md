# トランスフォーム (Transform)

アセットの位置・回転・スケールを操作するノード群です。

---

| 英語名             | 日本語名           | 説明                         |
| ------------------ | ------------------ | ---------------------------- |
| Get Scale          | スケールを取得     | スケールを取得する           |
| Set Scale          | スケールを設定     | スケールを設定する           |
| Get Local Position | ローカル位置を取得 | ローカル座標の位置を取得する |
| Get World Position | ワールド位置を取得 | ワールド座標の位置を取得する |
| Get Position       | 位置を取得         | 位置を取得する               |
| Set Position       | 位置を設定         | 位置を設定する               |
| Get Rotation       | 回転を取得         | 回転を取得する               |
| Set Rotation       | 回転を設定         | 回転を設定する               |
| Look At            | 注視               | 対象へ向けて注視させる       |
