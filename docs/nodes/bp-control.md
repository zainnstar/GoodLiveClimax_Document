# BP制御 (BP Control)

BP（ブループリント）オブジェクト自体の有効化・無効化・参照取得を行うノード群です。

---

| 英語名                   | 日本語名                     | 説明                                   |
| ------------------------ | ---------------------------- | -------------------------------------- |
| Switch Blueprint         | ブループリントを切り替え     | 対象ブループリントへ切り替える         |
| Blueprint Name           | ブループリント名             | 現在対象のブループリント名を取得する   |
| Get Blueprint Is Enabled | ブループリント有効状態を取得 | ブループリントの有効状態を bool で返す |
