# インストール

## 動作環境

| 項目 | 要件                    |
| ---- | ----------------------- |
| OS   | Windows 10 / 11 (64bit) |
| GPU  | NVIDIA GeForce推奨      |
| VRAM | 8GB以上推奨             |
| RAM  | 16GB以上推奨            |

---

## ダウンロード

[Boothページ](https://goodlucklabshop.booth.pm/items/8390156)

---

## セットアップ手順

### 1. ZIPを展開する

ダウンロードしたZIPファイルを任意のフォルダに展開してください。
フォルダには2つのzipファイルが含まれているので、こちらも展開してください。

- GoodLiveClimax
- GoodLiveClimaxController

---

### 2. 起動する

展開したフォルダ内の `GoodLiveClimax.exe` `GoodLiveClimaxController.exe` をダブルクリックして起動します。

---

### アップデート

Boothから新しいバージョンをダウンロードし、ZIPファイルを展開します

#### Climax本体

新しいフォルダ内のStreamingAssetsフォルダに、古い方のStreamingAssetsフォルダを上書きしてください。
GoodLiveClimax_ver260101_00000_Data 内の StreamingAssets

#### Climaxコントローラー

展開したフォルダの中で、ClimaxはStreamingAssetsフォルダ、ControllerはDataフォルダを上書きしてください。

---
