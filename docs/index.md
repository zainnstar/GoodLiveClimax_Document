# GoodLiveClimax

**個人VTuber向けライブ演出ソフト**

GoodLiveClimaxは、個人VTuberが**一人でライブを成立させる**ことを目的として作られた演出エンジンです。  
Unityをバックエンドに、カメラ・ライト・レーザー・トラッキングなどの演出要素をコントロールできます。

---

## 主な特徴

- **タイムライン連動** — Chataigneシーケンスと連携した再現性の高い演出
- **オーディオリアクティブ** — 音楽に自動で反応するビジュアルエフェクト
- **Spout2出力対応** — OBS等の配信ソフトに映像を直接送信
- **OSC通信** — 外部コントローラやソフトとリアルタイム連携
- **豊富なアセット** — カメラ・ライト・エフェクトなど多彩な演出要素
- **シーン管理** — 演出の切り替えやプリセット保存が可能
- **自作MOD対応** — アセットを追加して3Dモデル空間を自由にカスタマイズ

---

## 将来の実装予定の機能

- **コラボ機能** — 複数のVTuberが同時にライブを行える機能
- **配信ページとの連携** — youtubeやtwitchの配信ページのコメントやスーパーチャットに反応する演出
- **アセットの拡充** — 正式版リリースに向けて、さらに多くのアセットを追加予定
