# ポストプロセス（アセット）

画面全体にかける後処理エフェクトを管理するアセットです。見た目の方向性を先に置くための雛形ページです。

---

## 役割

- 画面全体の色調補正
- ブルームやぼかしの適用
- 演出ごとの見た目切り替え

---

## 主要設定

| 項目       | 内容                     |
| ---------- | ------------------------ |
| プリセット | あらかじめ用意した見た目 |
| 強度       | エフェクトの適用量       |
| 有効化     | ON / OFF                 |

---
