# オーディオリアクティブ（アセット）

音量や周波数帯に応じて見た目を変えるためのアセットです。演出の反応先を先に置いておくための雛形ページです。

---

## 役割

- 音量変化に反応する演出
- 周波数帯ごとの簡易モジュレーション
- ライトやエフェクトへの入力元

---

## 主要設定

| 項目     | 内容                            |
| -------- | ------------------------------- |
| 入力元   | オーディオプレイヤー / 外部音源 |
| 反応対象 | 色 / 強さ / 位置 / サイズ       |
| 感度     | 反応の強さ                      |

---

## 今後追記する内容

どの演出に接続するか、どの帯域を使うかは、機能確定後に詰めます。
