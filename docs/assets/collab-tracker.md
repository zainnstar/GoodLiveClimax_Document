# Collab Tracker（アセット）

複数人作業や外部連携のためのトラッキング中継アセットです。まずは置き場だけ用意した雛形です。

---

## 役割

- 外部入力の中継
- 複数ソースの整理
- コラボ向けの状態共有

---

## 主要設定

| 項目     | 内容                   |
| -------- | ---------------------- |
| 入力種別 | 追跡 / イベント / 状態 |
| 共有先   | 他アセット / パネル    |
| 有効化   | ON / OFF               |
