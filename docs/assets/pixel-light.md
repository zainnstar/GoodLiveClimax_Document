# ピクセルライト（アセット）

ピクセル単位の光表現を扱うためのアセットです。簡易な発光点の雛形ページです。

---

## 役割

- 小さな発光点の配置
- 色や明るさの制御
- 画面演出のアクセント

---

## 主要設定

| 項目   | 内容              |
| ------ | ----------------- |
| 色     | 発光色            |
| 強さ   | 輝度              |
| サイズ | 1点あたりの見た目 |
