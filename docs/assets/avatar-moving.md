# Avatar Moving（アセット）

アバターの移動や追従をまとめるためのアセットです。移動補助の置き場として使う雛形ページです。

---

## 役割

- アバター位置の補正
- 追従やオフセットの管理
- 移動演出の補助

---

## 主要設定

| 項目   | 内容               |
| ------ | ------------------ |
| 対象   | 移動させるアバター |
| 追従先 | 基準となる位置     |
| 補正量 | オフセット値       |

---

## 今後追記する内容

移動方式やトラッキングとの連携が決まったら追記します。
