# FBX（アセット）

外部モデルをシーンに置くためのアセットです。読み込みの入口だけ先に用意した雛形ページです。

---

## 役割

- 外部3Dモデルの配置
- モデル差し替えの受け皿
- 小道具や背景物の追加

---

## 主要設定

| 項目     | 内容             |
| -------- | ---------------- |
| ファイル | FBXモデル        |
| スケール | 読み込み時の倍率 |
| 配置     | 初期位置         |
