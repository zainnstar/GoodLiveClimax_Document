# Add Shader（アセット）

既存オブジェクトに追加シェーダーを重ねるためのアセットです。効果を後付けするための雛形ページです。

---

## 役割

- アウトラインなどの追加表現
- オブジェクト単位の見た目拡張
- 既存マテリアルの補助

---

## 主要設定

| 項目       | 内容                 |
| ---------- | -------------------- |
| 対象       | 適用するオブジェクト |
| シェーダー | 追加する表現         |
| 有効化     | ON / OFF             |
