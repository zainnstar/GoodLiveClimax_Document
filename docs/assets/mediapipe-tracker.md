# MediaPipe トラッカー（アセット）

Webカメラからトラッキング入力を得るためのアセットです。顔・手・体の入力元をまとめる雛形ページです。

---

## 役割

- カメラ映像の取得
- MediaPipe系のランドマーク抽出
- 他アセットへのトラッキング供給

---

## 主要設定

| 項目   | 内容               |
| ------ | ------------------ |
| カメラ | 使用するWebカメラ  |
| 解像度 | 追跡時の入力サイズ |
| 感度   | 検出の反応量       |

---

## 今後追記する内容

顔・手・姿勢の個別設定は、実装差分に合わせて追記します。
