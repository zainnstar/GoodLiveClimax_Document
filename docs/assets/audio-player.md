# オーディオプレイヤー（アセット）

音声ファイルを再生するためのアセットです。BGMや効果音を、シーン内の演出と合わせて扱うための雛形ページです。

---

## 役割

- 音声ファイルの再生
- ループ再生の切り替え
- 再生位置や音量の調整

---

## 主要設定

| 項目     | 内容                 |
| -------- | -------------------- |
| ソース   | WAV / MP3 / OGG など |
| 再生方法 | 単発 / ループ        |
| 音量     | 再生時の基本音量     |

---

実際の入力方法、トリガー連携、再生中の状態表示などは、実装に合わせて追記します。
