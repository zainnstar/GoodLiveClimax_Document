# VMC トラッカー（アセット）

VMC系の入力を受けて、アバターや各種演出に反映するためのアセットです。

---

## 役割

- VMCプロトコル入力の受信
- アバター状態の同期
- 外部トラッキングとの接続点

---

## 主要設定

| 項目   | 内容              |
| ------ | ----------------- |
| 受信元 | 外部VMC送信アプリ |
| ポート | 受信用ポート番号  |
| 有効化 | ON / OFF          |

---

## 今後追記する内容

実際の対応ボーンや表情の取り扱いは、実装に合わせて足します。
