# モーションレコーダー（アセット）

動きの記録と再生を行うためのアセットです。後から演出を再利用するための雛形ページです。

---

## 役割

- モーションの記録
- 記録した動きの再生
- 簡易なプリセット保存

---

## 主要設定

| 項目     | 内容                 |
| -------- | -------------------- |
| 記録対象 | 位置・回転・表情など |
| 再生方法 | ループ / 単発        |
| 保持時間 | 記録データの長さ     |

---

## 今後追記する内容

保存形式や再生開始条件は、機能が固まり次第追記します。
