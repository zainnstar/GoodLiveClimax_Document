# 配信連携

配信ソフトや外部サービスとの連携をまとめるパネルです。まずは導線だけ用意した雛形ページです。

---

## 役割

- 配信ソフトとの接続
- 外部連携の起点
- 出力系設定のまとめ

---

## 主な設定

| 項目     | 内容                 |
| -------- | -------------------- |
| 出力先   | OBSなど              |
| 連携方式 | Spout / OSC / その他 |
| 有効化   | ON / OFF             |

---

## 今後追記する内容

連携対象が固まったら、個別の手順を追記します。
