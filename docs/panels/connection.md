# 接続

Unityや外部機器との接続状態を確認するパネルです。接続周りの情報をまとめる雛形ページです。

---

## 役割

- WebSocket接続の確認
- OSCなど外部接続の状態確認
- 再接続の入口

---

## 主な設定

| 項目   | 内容               |
| ------ | ------------------ |
| 接続先 | Unity / 外部ツール |
| 状態   | 接続済み / 未接続  |
| 再接続 | 再試行操作         |
