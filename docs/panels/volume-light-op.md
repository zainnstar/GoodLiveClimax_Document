# VolumeLightOp

VolumeLight系アセットを制御するためのパネルです。ライト演出の調整窓口としての雛形ページです。

---

## 役割

- ボリュームライトの制御
- 色や強さの変更
- 演出プリセットの切り替え

---

## 主な操作

| 操作         | 内容             |
| ------------ | ---------------- |
| グループ選択 | 対象を切り替える |
| 強さ調整     | 光量の変更       |
| パターン     | 演出の切り替え   |

---
