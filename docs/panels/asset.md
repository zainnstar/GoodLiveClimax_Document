# アセット

アセットの追加・一覧操作をまとめるパネルです。管理系の入口だけを先に置いた雛形ページです。

---

## 役割

- アセット追加
- アセット一覧の確認
- 重要アセットへのアクセス

---

## 主な操作

| 操作     | 内容                 |
| -------- | -------------------- |
| 追加     | 新しいアセットを作成 |
| 削除     | 選択アセットを削除   |
| 名前変更 | 表示名を変更         |

---

## 今後追記する内容

アセット種別ごとの導線が決まったら追記します。
