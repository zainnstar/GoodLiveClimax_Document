# ランタイムライト管理

実行中のライトをまとめて確認・差し替えするためのパネルです。運用時の管理窓口としての雛形ページです。

---

## 役割

- 実行中のライト管理
- その場での差し替え
- 状態の簡易確認

---

## 主な操作

| 操作     | 内容                 |
| -------- | -------------------- |
| 追加     | 新しいライトを登録   |
| 置換     | 別のライトへ差し替え |
| 状態確認 | 現在の有効状態を確認 |
