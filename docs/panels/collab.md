# コラボ

コラボパネルは、複数人で同じセッションに参加するための接続管理パネルです。

## できること

- Host（主催）としてセッションを作成
- Client（参加者）として既存セッションに参加
- Motion / Expression / Trigger / シーン共有の送受信切り替え
- 参加中 peer（相手）の状態確認

## 接続に必要な3点

接続先に共有する情報は次の3つです。

1. Signaling URL
2. ルームID
3. パスワード

## 基本手順（Host）

1. Signaling サーバーを起動する
2. コラボパネルで Signaling URL を設定する
3. `ランダム ID 生成` でルームIDを作成する
4. パスワードと表示名を入力する
5. 接続役割を `ホスト` にして `接続開始` を押す
6. Signaling URL / ルームID / パスワードを参加者へ共有する

## 基本手順（Client）

1. Host から受け取った Signaling URL / ルームID / パスワードを入力する
2. 接続役割を `クライアント` にする
3. `接続開始` を押す

## URLの使い分け

- 同じPC内: `ws://127.0.0.1:21752/`
- 同じLAN内: `ws://192.168.x.x:21752/`
- インターネット越し: `ws://<global-ip>:21752/`（検証）または `wss://<domain>/`（推奨）

補足:

- `LAN URL を自動入力` は同一LAN向けURLを自動設定する補助です。
- インターネット越し接続では、ルーターのポート転送など別途ネットワーク設定が必要です。

## 送受信設定の目安

- 演者プリセット: 通常の相互同期向け
- オペレータープリセット: Trigger/Variable中心の運用向け

## よくある問題

### 接続開始ボタンが押せない

- Controller と Unity の通常 WebSocket 接続が未成立です。
- 先に Unity を起動し、通常接続状態を確認してください。

### Signaling connection closed が続く

- Signaling URL が誤っている
- Signaling サーバーが起動していない
- LAN / ルーター / ファイアウォール設定で到達できない

### LANは繋がるがインターネット越しで繋がらない

- ルーターのポート転送未設定
- 回線が CGNAT のため外部着信不可

## 運用メモ

- 接続状態（live session）はシーン保存対象ではありません。
- 再起動後は必要に応じて再接続してください。
